OCS网课助手集成指南

📚 如何导入到OCS网课助手

1

启动EduBrain AI服务

确保EduBrain AI服务正在运行，您可以通过访问首页或管理面板确认服务状态。 

# 启动服务
python main.py
2

配置OCS网课助手

在OCS网课助手中添加自定义题库接口：

  • 打开OCS网课助手设置
  • 进入"题库设置" → "自定义接口"
  • 添加新的接口配置
3

填写接口信息

按照以下信息配置接口：

接口名称
EduBrain AI
接口地址
http://localhost:8000/api/search
请求方法
POST
Content-Type
application/x-www-form-urlencoded
4

配置请求参数

设置以下参数映射：

题目内容 title
题型 type
选项 options
上下文 context
5

测试连接

保存配置后，点击"测试连接"验证接口是否正常工作。

测试题目： "中国的首都是哪里？"

期望结果： 返回答案"北京"

💡 注意事项

  • 确保EduBrain AI服务运行在正确的端口（默认8000）
  • 如果使用外部题库，请确保external_databases.json配置正确
  • 网络连接问题可能导致查询失败，请检查防火墙设置
  • 建议定期检查服务状态，确保系统正常运行

🚀 快速测试接口

1. 启动服务

python main.py

2. 测试搜索接口

curl -X POST "http://localhost:8000/api/search" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "title=中国的首都是哪里？&type=single"

3. 测试健康检查

curl "http://localhost:8000/api/health"
